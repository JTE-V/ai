# VulnHunter 规则集（它的"纪律"）
# 本文件是红线 1 的落点：是否调模型、用哪个模型、如何分级、何时告警，全部由这里决定。
# 用户训练 = 编辑本文件。每次修改记录进 feedback_log.txt。

## 1. 路由规则（何时调用 LLM）——L1 → L2 → L3 渐进式查询

L1 缓存命中（直接返回，不调用任何模型）：
- cve 已存在于已知库，且影响面判定已完成 → 返回缓存结果
- 数据源自带完整 CVSS 且无新增利用情报 → 返回

L2 规则粗筛（不调用模型）：
- 匹配条件：组件名 ∈ 关注清单，且版本表达式 与 资产版本区间 相交
- 匹配失败 → 归档，不调用模型
- 匹配成功 → 进入 L3

L3 语义精筛（调用模型，模板 01 + 02）：
- 满足 L2 且以下任一成立：
  - public_exploit == yes
  - cwe ∈ {79, 89, 78, 22, 502, 94, 434} 且 cvss >= 7.0
  - cve ∈ CISA KEV（已知被利用目录）
- 否则 → 归档

模型选择（算法黑箱层）：
- 因素提取（模板 01/02/03）：openai/gpt-4o-mini（便宜快）
- 利用链推理（模板 04，仅 critical/high）：openai/gpt-4o 或 anthropic/claude-sonnet
- 主模型不可用 → 降级：只用 L2 规则结果 + response.meta.degraded=true（禁止静默降级）

## 2. 严重性规则（等级 = 规则计算，模型只提供因素）

因素（来自模板 02）：exploitable, public_exploit, internet_facing, auth_required,
                 attack_complexity, impact.{confidentiality, integrity, availability}

critical：public_exploit == true AND internet_facing == true
high：cvss >= 7.0 OR public_exploit == true OR impact.confidentiality == high
medium：cvss >= 4.0
low：其余

资产重要性加权（乘在最终告警优先级上）：
- critical_asset ×2（对外核心服务）
- internal ×1
- dev ×0.5

## 3. 告警规则

- critical / high → 立即告警 + 触发模板 04 利用链深度分析
- medium → 每日汇总告警一次
- low → 归档，不打扰
- 同一 cve 重复出现且判断未变 → 去重，不重复告警（防"情报爆发日"风暴）

## 4. 防护参数（QueryGuardian 配置，文本即配置）

- 看门狗：单次分析超时 30s，重试最多 2 次（指数退避）
- 熔断：连续 5 次失败 → 短路 60s，期间只走 L1/L2 规则
- 背压：并发分析 ≤ 10，QPS ≤ 20；溢出 → 降级为"已记录，待处理"
- 内存 GC：上下文水位 80% → 滑动摘要压缩历史情报
- 审计：每次模型调用记录 provider / model / latency / tokens / cve → feedback_log 可追溯
- 自动修复(E04): severity 计算须做版本比较: 资产版本大于等于修复版本则不受影响。

## 法律规则（梦新懂法律 —— 领域规则）

识别：输入含"辞退/借条/离婚/押金/赔偿/工资/合同纠纷"等 → 法律领域。

提取（法律字段）：
- legal_area: 劳动法/借贷/婚姻/租赁/刑事
- legal_basis: 引用《XX法》第X条（不确定则声明"请以最新文本为准"）
- entitled: 陈述法律规定（可主张什么），禁止绝对化承诺（红线2）
- suggestions: 建议步骤（标为建议）
- disclaimer: 必须有（红线1: "仅供参考，不构成法律意见，建议咨询律师"）
- evidence: 逐字来自 input.txt 的关键事实片段

红线（法律版）：
- 不冒充律师（红线1）: 必须免责声明
- 不保证结果（红线2）: 禁"必赢/稳了/肯定能"
- 引用真实法条（红线3）: 不编造，不确定就声明
- 区分事实与建议（红线5）: entitled=法律规定, suggestions=建议
- 不越权（红线6）: 不判决/不定案，复杂案情建议咨询律师(12348)

反例：
- "你肯定能赢" → 违反红线2
- 无 disclaimer → 违反红线1
- "判处被告..." → 违反红线6（越权）

# 通用联网检索 (框架级, 2026-08-07)
- 数据库找不到 → 网页找, 别当字典 (梦新核心能力)
- 实现: run_model._web_lookup (多源可插拔 WEB_SOURCES + 缓存 web_cache/)
- 源注册: _register_source(name, fn); 失败返回 None 不编造 (红线3)
- 缓存优先: 查过即缓存, 离线可用 (像 nvd_cache)
- 失败标注: note 记录"网络受限/源不可达", 不静默不编造
- 现有源: NVD (通用 CVE/关键词); 后续加法规/百科源即注册
