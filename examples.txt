# VulnHunter 教材（few-shot 示例）
# 正例教会它"做对长什么样"，反例教会它"做错长什么样"。
# 用户训练的核心手段：在这里加一条例子，比改十条规则更有效。

## 正例 1：外部情报结构化（模板 01 的输出应当如此）

输入片段：
> "A vulnerability was found in Apache Log4j2 2.0-beta9 through 2.14.1. An attacker
> who can control log messages can execute arbitrary code loaded from LDAP servers."

输出：
{
  "cve": null,
  "unrelated": false,
  "affected_component": "Apache Log4j2",
  "affected_versions": [">=2.0-beta9, <=2.14.1"],
  "cwe": null,
  "cvss": null,
  "public_exploit": "unknown",
  "attack_vector": "network",
  "summary": "Log4j2 2.0-beta9 至 2.14.1 可通过可控日志消息从 LDAP 加载任意代码执行。",
  "evidence": ["An attacker who can control log messages can execute arbitrary code loaded from LDAP servers."]
}

要点：原文没写 CVE 号、CWE、CVSS → 全给 null/unknown，不编造；evidence 逐字引用。

## 正例 2：内部分析如实标注（模板 03）

扫描发现 pip-audit 报 `requests==2.25.0` 受 CVE-2023-4863 影响，但资产清单里只有 `requests==2.31.0` →
输出 findings 中 installed_version=2.31.0 且落入 unmatched 说明，notes 标注"版本已修复，无需操作"。
禁止为了"好看"强行把 2.31.0 判为受影响。

## 反例 1：编造信息（违反红线 4，绝对禁止）

❌ 输出里出现原文没有的 "CVSS: 9.8, CWE-502, 已在野利用" —— 这是伪造来源。
✅ 应输出 cvss: null, cwe: null, public_exploit: "unknown"。

## 反例 2：越权定级（违反红线 1）

❌ 模型输出直接写 "severity: critical，立即告警"。
✅ 模型只输出因素 {exploitable, public_exploit, internet_facing, ...}，
   最终等级由 rules.txt 的 severity 规则计算。

## 反例 3：空话检测信号（模板 04）

❌ "signal": "检测恶意行为" —— 无法落地，protect_plass 不知道挂哪个 tracepoint。
✅ "signal": "java 进程发起到 389/636 端口的出站连接", "where": "connect tracepoint", "severity": "red"。

## 法律示例（梦新懂法律 —— 领域喂养）

### 正例 1：无故辞退赔偿（劳动法）
输入：我在公司干3年，无故被辞退，没补偿没通知，有合同和流水。
输出：
{
  "legal_area": "劳动法",
  "legal_basis": "《劳动合同法》第47条（经济补偿）、第87条（违法辞退赔偿金）",
  "entitled": "违法辞退可主张赔偿金(2N)；合法辞退经济补偿(N)",
  "suggestions": ["保留证据(合同/工资流水/通知)", "劳动仲裁(时效1年)", "必要时法院起诉"],
  "disclaimer": "仅供参考，不构成法律意见，建议咨询律师",
  "evidence": ["无故被辞退", "没给任何补偿", "没提前通知"]
}

### 正例 2：借钱不还（借贷）
输入：朋友借我5万不还，有转账记录和借条，怎么办？
输出：
{
  "legal_area": "借贷",
  "legal_basis": "《民法典》第675条（还款期限）、第188条（诉讼时效3年）",
  "entitled": "可要求返还借款本金及利息",
  "suggestions": ["保留借条/转账记录/催收记录", "先协商", "协商不成起诉(小额诉讼)"],
  "disclaimer": "仅供参考，不构成法律意见，建议咨询律师",
  "evidence": ["借5万不还", "有转账记录和借条"]
}

### 反例 1：绝对化承诺（红线2）
❌ "entitled": "你肯定能赢，稳了" —— 违反红线2（不保证结果）。
✅ "entitled": "违法辞退可主张赔偿金(2N)" —— 陈述法律规定，不承诺结果。

### 反例 2：无免责声明（红线1）
❌ 输出无 disclaimer 字段 —— 违反红线1。
✅ 必须含 disclaimer: "仅供参考，不构成法律意见，建议咨询律师"。
