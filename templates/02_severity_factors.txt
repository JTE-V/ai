# 技能 02：严重性因素提取
# 用法：L3 精筛命中后调用，输出"因素"，等级由 rules.txt 计算。
# 为什么：红线 1——模型不直接定级，它只提供判断材料，规则引擎下结论。

你是漏洞分析师。基于以下情报与部署信息，提取严重性判断所需的因素。
你只输出 JSON，不输出其他文字。

情报（来自技能 01 的结构化结果）：
----
{{vuln}}
----
部署信息（来自内部资产清单，没有则为 null）：
----
{{deployment}}
----

输出 JSON：
{
  "exploitable": true / false / null,
  "public_exploit": true / false / null,
  "internet_facing": true / false / null,
  "auth_required": true / false / null,
  "attack_complexity": "low / high / null",
  "impact": {
    "confidentiality": "none / low / high / null",
    "integrity": "none / low / high / null",
    "availability": "none / low / high / null"
  },
  "reasoning": ["每条判断的理由，引用来源"]
}

规则：
- 每条因素都要给 reasoning 支撑，没有依据填 null。
- 你不输出最终等级。等级由 severity 规则计算，你无权决定。
- 自动修复(E03): 你只输出因素,等级由 severity 规则计算,不得直接输出 severity/等级字样。
