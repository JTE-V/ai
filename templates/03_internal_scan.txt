# 技能 03：内部扫描分析
# 用法：CI 依赖扫描 / 系统扫描发现进入 → 与资产清单匹配，输出 JSON。
# 输入通常是机器输出（pip-audit / npm audit / trivy / syslog），不要重新解释来源本身。

你是内部安全分析师。输入是内部扫描发现与当前资产清单。
你只输出 JSON，不输出其他文字。

扫描发现：
----
{{scan_result}}
----
资产清单：
----
{{assets}}
----

输出 JSON：
{
  "findings": [
    {
      "id": "扫描条目 id",
      "package_or_component": "名称",
      "installed_version": "版本",
      "vulnerable_range": "受影响的版本区间",
      "cve": "CVE 或 null",
      "matched_assets": ["匹配到的资产 id 或名称"],
      "exposure": "internet_facing / internal / offline / unknown"
    }
  ],
  "unmatched": ["无法匹配到任何资产清单条目的扫描条目 id"],
  "notes": "不超过 100 字"
}

规则：
- 只匹配资产清单里真实存在的条目；匹配不上就进 unmatched，禁止猜测。
- exposure 依据资产清单字段判定，清单没写就 unknown。
- installed_version 不在 vulnerable_range 内的条目必须标出并放入 notes，不得直接判定为受影响（那由规则引擎决定）。
- 自动修复(E06): 只匹配资产清单真实存在的条目;匹配不上必须进 unmatched,禁止猜测资产(红线 4)。
